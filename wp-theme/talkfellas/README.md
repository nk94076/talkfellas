# TalkFellas WordPress Theme

## Install
Appearance → Themes → Add New → Upload Theme → `talkfellas.zip` → Activate.
Recommended plugins: Rank Math SEO (or Yoast), LiteSpeed Cache / WP Super Cache.

## Control everything from WordPress
| Section | Where to edit |
|---|---|
| Logo | Appearance → Customize → Site Identity |
| Colours, footer text, social links | Customize → TalkFellas Homepage → Brand, Colours & Footer |
| Hero text & buttons | Customize → TalkFellas Homepage → 1. Hero |
| Hero slider posts | Edit post → "TalkFellas Options" box → Show in hero slider |
| Category bar / Explore by Category | Posts → Categories → Icon, Image, Show on homepage, Order |
| Trending topics | Appearance → Menus → create menu → location "Trending Topics bar" |
| Latest Stories | Automatic (newest posts) |
| Popular This Week | Automatic (theme counts views) |
| Reviews banner | Customize → 4. Reviews Banner |
| Editor's Picks | Edit post → tick "Editor's Pick" |
| How-To Guides | Customize → 7. How-To Guides → choose category |
| Newsletter | Customize → 8. Newsletter (emails saved in Tools → Subscribers, or paste a Mailchimp form URL) |
| Stats | Customize → 9. Stats |
| Header menu / Footer columns | Appearance → Menus → Header Menu, Footer column 1-4 (menu name = column title) |
| Show/hide any section | Each Customizer section has a "Show section" checkbox |

## Affiliate product box (in any post, Shortcode block)
```
[product rank="1" name="Product" image="IMAGE URL" score="9.6" badge="Best Overall" link="AFFILIATE URL"]
Feature one | Feature two | Feature three
[/product]
```
